# 尾片：版式与排版原则

## 顺序

**先问文案，再排版。** 至少要问三件：祝福或主标语写什么、署名写谁、要不要英文与页脚。排完再改文字等于重做一版。

## 品牌配置放在技能外面

技能本身不带任何机构的徽标、色值或名称。具体品牌走一个 JSON 配置文件，由 `--profile` 传入：

```json
{
  "bg": "#2B2620", "accent": "#C9A227", "paper": "#FAF6EE", "inner": "#4A423A",
  "logo": "/绝对路径/logo.png",
  "en": "XXXX SCHOOL", "top": "XXXX", "foot": "EST. 19XX　XXXX"
}
```

不传 `--profile` 时用中性深色底（墨黑 + 金），也不放徽标——适合还没有品牌规范的个人使用。
品牌素材属于机构资产，随技能分发前必须拿到授权；默认不进技能包。

## 两种版式

**left（左对齐·杂志式）**：英文名做眉标放左上，徽标右上，主标语两行左对齐，署名与细线压在下沿。适合宣传物料、公众号封面。

**center（居中·落款）**：徽标居中，主标语两行等宽（各 4 字最佳，宽度一致才对得齐），金线 + 署名 + 英文。适合发家长群、正式落款。

## 排版禁忌（这几条最容易把尾片做丑）

1. **一句长文案拆成"三词"排版**：署名行若在连接词两边加大空格，视觉上会断成三段；应该让字距一致、读成一句。
2. **两行字号不同又强行居中**：宽度不一致，左右必然参差。要么同字号，要么左对齐。
3. **中文加大字距**：中文大字号加 tracking 会显得松垮断裂；字距只给英文加。
4. **金色滥用**：金色只做署名/英文/细线；主标语必须是白色或米白。
5. **元素贴边**：文字块要留 ≥ H×0.08 的下边距；徽标与正文之间留 ≥ 60px 呼吸。
6. **停留太短**：两行字读不完。3.5–4 秒，且音乐在尾片前 2.5 秒渐隐干净。
7. **徽标直接叠在深底上**：白底徽标会有白块；必须放在白色卡片里，且不变形、不换色、不投影。

## 徽标取用

只从 `--profile` 的 `logo` 路径读，不做像素改动。技能包里不放任何机构的徽标文件。
