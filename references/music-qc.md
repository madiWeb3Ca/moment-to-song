# 音轨质检口径

曲库那套检查不能直接搬过来。自创音乐多出三层风险：文件可能是假的、词可能唱漏或唱成念白、旋律与响度不稳定。

## 六条硬指标（机器可判，全 PASS 才往下做画面）

| # | 检查项 | 判据 |
|---|---|---|
| 1 | 容器真实 | `codec_name` 必须是 mp3/aac；音乐工具常把 PCM/WAV 存成 `.mp3` |
| 2 | 时长对齐 | 与目标误差 ≤ 0.05s；成片帧数 = `round(dur×fps)` |
| 3 | 响度/削波 | mean −19 ~ −14.5 dB、max ≤ −0.3 dB；偏轻先 `loudnorm` 再**复测** |
| 4 | 静音空隙 | 标出 `<-33dB` 且 `≥0.06s` 的段落（字幕断开、镜头停留用） |
| 5 | 拍点稳定 | 拍间隔 std ≤ 0.05s；BPM 与拍间隔要能互相解释 |
| 6 | 词完整性 | 锁定歌词逐句比对 ASR；同音字放行，漏句/改词判失败 |

一次跑完：

```bash
python3 scripts/music_qc.py 试听A.mp3 --expect-dur 48 --lyrics lyrics.txt
```

`--lyrics` 需要 `ASR_MODEL_DIR` 指向 faster-whisper 本地模型目录；没装就 SKIP，不假装通过。

## 三条人耳指标（不可自动判定）

1. **悠不悠扬**：有没有起伏、句尾有没有拖音与气息。纯念白式唱法直接否决——这类片子曾只拿到 70 分。
2. **情绪对不对**：豪迈的不许唱成恱情，恱情的别唱成喊麦；同一条提示词两次生成，气质常有差异。
3. **有没有怪东西**：突然变调、器乐突断、半句含糊、莫名念白、多人合唱。**听首、中、尾三个点**，不要只试开头。

规则：主观项由用户拍板，模型只给候选与差异说明，绝不写"已确认好听"。

## 四个真实翻车案例

| 症状 | 根因 | 处置 |
|---|---|---|
| 试听全部放不出声，用户回"没有啊" | 返回 PCM/WAV，按 `.mp3` 后缀保存 | `ffprobe` 验 codec，转真 MP3；交付前自己顺着链接下载验一次 |
| "不悠扬，70 分" | 提示词写成"轻声吟唱/贴近说唱"，出来是念白 | 补旋律线条、句尾拖长、副歌轻抬；并改成先试听再出片 |
| BPM 报 89.29，实听 92–95 | 全局估计与局部拍间隔不一致 | 以**拍间隔序列**为准，BPM 只作参考；切点吸附实拍点表 |
| 成片 mean −26.7 / max −8.3，几乎听不见 | 只做了一次 `loudnorm` 没复核 | `loudnorm` 后 `volumedetect` 复测，不达标再 `volume`+`alimiter` |

## 提升 ASR 命中率的三个动作

- 数组输入（`soundfile.read`），不要传文件路径；
- `language="zh"` 用关键字，别用位置参数；
- `initial_prompt` 传整首词，命中率明显提升；
- 返回值是生成器，必须 `list(segs)`。
